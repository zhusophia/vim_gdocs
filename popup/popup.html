Vim for Google Docs

Modes

iInsert mode
aInsert after cursor
IStart of line, insert
AEnd of line, insert
vVisual mode
VVisual line mode
EscBack to Normal mode

Movement

h j k lLeft, down, up, right (H J K L too)
wNext word
bPrevious word
eEnd of word
0 $Start / end of line
ggTop of document
GBottom of document
5jCounts work: move 5 down

Editing

d + motionDelete (dw, dd)
c + motionChange (cw, cc)
y + motionYank / copy (yw, yy)
pPaste
uUndo
r / Ctrl RRedo
oNew line below
ONew line above
BackspaceDelete (any mode)

Command line (Normal mode)

:42 EnterGo to line 42
:+5 EnterGo 5 lines down
:-5 EnterGo 5 lines up
EscCancel

The left gutter shows line numbers; the current line is bold.

Always handled by Docs

Ctrl/Cmd/Alt shortcuts (Ctrl+C, Ctrl+V, Ctrl+Shift+V, Ctrl+Y, Ctrl+B ...) work in every mode.
